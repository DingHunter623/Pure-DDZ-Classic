# Pure-DDZ-Classic Development Plan

## Product Position
A pure offline Chinese Dou Dizhu game designed for parents and seniors.

## Core Principles
- No ads
- No login
- No payment
- No network dependency
- No user data collection

## V1.0 Goals

### Game Engine
- 54 card deck
- 3 player Dou Dizhu
- Landlord bidding
- Card comparison rules
- Bomb and rocket rules
- Spring win detection

### AI
- Easy / Normal / Hard modes
- Natural decision making
- Avoid obvious cheating behavior

### Senior Friendly UI
- Large cards
- Large buttons
- Large fonts
- High contrast interface
- Simple Chinese prompts

### Audio
- Traditional Dou Dizhu background music
- Classic card playing sounds
- Chinese voice announcements
- Volume controls

## Technology Direction
- Android native
- Kotlin
- Offline APK
- Local storage

## First Milestone
Create Android project skeleton and implement card model + game engine foundation.

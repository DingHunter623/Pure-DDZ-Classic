# Pure-DDZ-Classic Development Roadmap

## Product Strategy

Develop the computer web version first, then package and adapt it into an Android APP.

The development principle is similar to a desktop application architecture:
- Build a complete playable web application first.
- Verify gameplay, UI, audio and user experience on PC.
- Reuse core logic for Android APP adaptation.

## Phase 1: Web Version

Technology direction:
- HTML5 + CSS3 + JavaScript/TypeScript
- Local offline storage
- No advertising SDK
- No login system
- No server dependency

Functions:
- 54-card deck
- Three-player Dou Dizhu
- AI opponents
- Large card display
- Senior-friendly UI
- Traditional background music
- Chinese voice prompts

## Phase 2: Android APP

- Package mature web/game engine into Android application.
- Adapt touch operation.
- Support APK installation.
- Maintain offline and clean experience.

## Design Goal

A simple, clean Dou Dizhu game for parents and seniors:

Open -> Play -> Enjoy

No advertisements, no complicated operations.

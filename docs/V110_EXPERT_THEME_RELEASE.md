# QilyLean 无广告斗地主｜简单娱乐，益智生活

Pure DDZ Classic v1.1.0｜QilyLean 智力强化主题版。

这款游戏源于一个真实的家庭需求：父母辈喜欢玩网页版斗地主，但实名注册、账号登录、验证码验证等流程，对不熟悉智能设备操作的老年人并不友好。产品因此坚持**无广告、无强制注册、操作简单、打开即玩**，希望让老年人的休闲娱乐更轻松、便捷、安全。

它也面向长期处理复杂问题分析、工程改善、项目管理和高强度思考的成年人。斗地主作为一种简单的益智活动，可以在轻松游戏中保持思考、缓解压力，让工作与生活更加平衡。

> 愿每一次出牌，都带来轻松与快乐；  
> 愿每一次思考，都保持活力与智慧。

## v1.1.0 能力

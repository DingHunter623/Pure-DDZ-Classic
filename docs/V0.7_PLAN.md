# Web V0.7 Playable Version Plan

Goal: Make the browser version playable as a complete single round of Dou Dizhu.

## Features

- Three-player table layout
- Human player 17-card display
- Two AI opponents
- Bottom cards display
- Landlord selection
- Click cards to select
- Play card button
- AI turn response
- Win/loss detection

## Release Direction

After playable Web version:

1. Add traditional background music
2. Add Chinese voice guidance
3. Improve AI strategy
4. Package desktop application
5. Package Android APK
